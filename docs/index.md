# caret

*Audience: people using caret with Claude Code, OpenCode, or pi.*

caret replaces your coding agent's terminal plan-approval prompt with a review page in
your browser. You read the plan as rendered text, comment on the lines that matter, then
approve it or request changes, and caret sends your feedback back to the agent. One
background process serves all your agent sessions, so you review several plans from one
browser tab.
