# caret

*Audience: people using caret with Claude Code, OpenCode, or pi.*

caret replaces your agent host's plan-approval prompt with a review page in your browser.
Your agent host is the coding tool caret plugs into: Claude Code, OpenCode, or pi. You
read the plan, comment on the lines that matter, then approve it or request changes. caret
sends your feedback back to the agent. One background service serves all your sessions, so
you review several plans from one browser tab.
